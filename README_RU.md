# ASCII Wallpapers

Стартовый Android-проект живых ASCII-обоев для Redmi Note 13 4G.

## Анимации
- Чёрная дыра · Куб
- Цифровой дождь
- Неоновая волна

## Как получить APK через GitHub Actions

1. Войди в GitHub и создай новый пустой репозиторий с названием `ASCII-Wallpapers`.
2. Загрузи в него всё содержимое этой папки (именно файлы и папки проекта, не ZIP-архив).
3. Открой вкладку **Actions** репозитория и подтверди разрешение на запуск Actions, если GitHub попросит.
4. Сборка начнётся автоматически после загрузки файлов в ветку `main`. Также её можно запустить вручную: Actions → Build Android APK → Run workflow.
5. Когда сборка завершится зелёной галочкой, открой её запуск, прокрути до **Artifacts** и скачай `ASCII-Wallpapers-APK`.
6. Распакуй скачанный архив — внутри будет `app-debug.apk`.

## Установка на Redmi Note 13 4G

Перенеси `app-debug.apk` на телефон, открой файл и подтверди установку. Затем запусти ASCII Wallpapers, выбери анимацию и нажми «Установить живые обои». В системном окне подтверди установку.

## Требования
- Android 6.0 или новее
- Android Studio не нужна, если используешь GitHub Actions
- Сборка использует GitHub Actions, Gradle 8.9 и JDK 17

Это тестовая debug-сборка, не опубликованная в Google Play.
